# eclipse-workspace-themer

Set the theme for a given workspace for Eclipse IDE. Focuses on the Java IDE specifically. Currently supplies one theme: gruvbox light. Uses [bubbletea](https://github.com/charmbracelet/bubbletea) and [lipgloss](https://github.com/charmbracelet/lipgloss).

## Building

1. clone
2. `go build`
3. copy `eclipse-workspace-themer` onto `$PATH`

## Usage

1. `cd` into your Eclipse workspace
2. Run `eclipse-workspace-themer`, select theme with arrow keys, then press enter.
